## 【無料部分】

「今日こそやるはずだったのに、また夜になってしまった」
「やることを考えるだけで疲れて、結局スマホを見ている」
「手帳を買うたびに、最初の数ページで止まる」

夜、布団の中で、こんなふうに自分を責めていませんか。

このまま何も変えずに半年が過ぎると、「やらなきゃ」の山は少しずつ高くなります。期限を過ぎた手続き、返していない連絡、手をつけていない片付け。量が増えるほど取りかかりにくくなり、「どうせ自分は」という気持ちだけが残ります。

でも、足りないのは根性ではありません。**自分の特性に合った「道具」**です。

### 海外では、ひとつのジャンルになっている

アメリカの個人向け通販サイト「Etsy」では、「ADHDプランナー」と呼ばれる書き込み式の手帳が数多く売られています。普通の手帳との違いは、次のような困りごとを前提に作られていることです。

- 覚えておくことが多いと、頭がいっぱいになる
- 作業にかかる時間を、短く見積もりがち
- 最初の一歩が大きいと、取りかかれない
- 楽しみがないと、気持ちが動かない

日本語で同じように使えるものがほとんどなかったため、これらの工夫を日本の暮らしに合わせて、A4で印刷できる9ページのシートにまとめました。

### 向いている人・向いていない人

向いている人
- やることが多いと固まってしまう人
- 時間の見積もりがいつもズレる人
- 普通の手帳が続かなかった人
- 診断の有無にかかわらず、先延ばしや時間管理に困っている人

向いていない人
- 紙に書くのがどうしても苦手な人（スマホ版は別の記事で用意する予定です）
- 医療的な治療法を探している人

### 先にお伝えしておくこと

このプランナーは、予定や作業を整理するための道具です。診断や治療の代わりにはなりません。また、使えば必ず先延ばしがなくなる、というものでもありません。できるのは、「何から手をつけるか」「どのくらい時間がかかるか」を、頭の中ではなく紙の上で考えられるようにすることです。

## 【有料部分】

### ダウンロード

（ここにPDF「プランナー本体.pdf」を添付）

A4用紙に印刷してください。家庭用プリンターがない場合は、コンビニのネットプリントでも印刷できます。何度でも印刷して使ってかまいません（個人利用に限ります。再配布はご遠慮ください）。

タブレットで書き込みたい場合は、PDFに書き込めるアプリ（iPadの「メモ」やGoodNotesなど）に読み込んで使えます。

### まずは「3枚だけ」から始める

9ページ全部を一度に使う必要はありません。最初の1週間は、次の3枚だけで十分です。

1. **ブレインダンプ**（週に1回、気になったとき）
2. **今日のページ**（毎日）
3. **週のふりかえり**（週末）

慣れてきたら、困りごとに合わせて残りのページを足します。

| 困りごと | 足すページ |
|---|---|
| 取りかかれない作業がある | タスク分解シート |
| 予定がいつも押す | 見積もり練習シート |
| 1週間があっという間に過ぎる | 週間タイムブロック |
| やる気が出ない | ごほうびメニュー |
| 続けたい習慣がある | 月間習慣トラッカー |

### 各ページの使い方のコツ

**ブレインダンプ**
書き出したら、今日やるものに★、誰かに頼めるものに→、やらなくていいものに✕をつけます。✕をつける作業が、実は一番大事です。「やらなくていい」と決めるだけで、頭の負担が減ります。

**今日のページ**
「今日の3つ」は、全部終わらなくても大丈夫です。1つ終われば十分な日もあります。「明日に回すこと」の欄に書いたものは、書いた時点で忘れてかまいません。

**タスク分解シート**
1つの一歩は15分以内が目安です。それでも手が止まるなら、まだ大きすぎます。「パソコンを開く」「ファイル名を決める」くらいまで小さくします。

**見積もり練習シート**
2週間ほど記録すると、「実際÷見積もり」の平均が出ます。これが自分の倍率です。たとえば1.8倍なら、30分と思った作業には約55分の枠を取ります。ズレるのは能力の問題ではなく、誰にでもある傾向です。

**ごほうびメニュー**
SNSや動画の連続再生のように、始めると止まりにくいものは「終わらないごほうび」です。使うなら時間を決めるか、別のものに置き換えます。

### AIでタスクを小さく分ける指示文（5種）

ChatGPT、Claude、Geminiなどに、そのまま貼り付けて使えます。【　】の部分を書き換えてください。名前や住所などの個人情報は入れないでください。

**1. タスクを2分の一歩まで分ける**

```
私は作業に取りかかるのが苦手です。次の作業を、1つあたり15分以内でできる小さな手順に分けてください。
最初の手順は「2分以内にできること」にしてください。
手順は多くても7つまでにして、それぞれに目安の時間（分）を付けてください。
作業：【例：確定申告の書類をそろえる】
```

**2. 頭の中を整理する（ブレインダンプの仕分け）**

```
次は、私が頭の中にあることを全部書き出したリストです。
「今日やる」「今週やる」「誰かに頼める」「やらなくていい」の4つに分けてください。
判断に迷うものは「確認が必要」として、何を確認すればいいかを1行で書いてください。
リスト：【書き出した内容を貼る】
```

**3. 時間の見積もりを現実的にする**

```
私は作業時間を短く見積もりがちで、実際には平均【例：1.8】倍かかります。
次の作業リストについて、私の見積もりに倍率をかけた現実的な時間と、今日の残り【例：4】時間に収まるかどうかを表にしてください。
収まらない場合は、明日に回す候補を提案してください。
作業と見積もり：【例：メール返信 15分、資料修正 30分、買い物 20分】
```

**4. 取りかかれないときの「最初の一言」を作る**

```
次の作業に、どうしても取りかかれません。
責めたり励ましすぎたりせず、今すぐできる最初の行動を1つだけ、具体的に提案してください。
その行動は、立ち上がらなくてもできるものだと助かります。
作業：【例：部屋の片付け】
```

**5. 1週間の予定を枠に置く**

```
次の予定と、今週やりたいことをもとに、週間の時間割を作ってください。
条件：1日に1〜2か所は空き時間を残す。1つの作業は90分以内にして、間に休憩を入れる。疲れやすい夕方以降には重い作業を置かない。
決まっている予定：【例：月〜金 9時〜18時 仕事】
今週やりたいこと：【例：役所の手続き、部屋の片付け、友人への返信】
```

**AIを使うときの注意**
- AIの提案は「たたき台」です。合わなければ遠慮なく直してください。
- 体調や服薬、診断に関することは、AIではなく医師に相談してください。

### 続かなかったときの戻り方

手帳が続かないのは、よくあることです。白紙の日があっても、そこから再開すれば大丈夫です。

- 空白の日は、埋めずにそのままにします。さかのぼって書く必要はありません。
- 戻るときは「今日のページ」1枚からにします。
- 2週間空いたら、ブレインダンプから始め直します。

このプランナーは「毎日きちんと書く人」のためのものではありません。「書けた日に、少し楽になる」ための道具です。

### 最後に

先延ばしや時間の見積もりの苦手さは、気合いだけでは変わりにくいものです。だからこそ、頭の中で頑張るのではなく、紙とAIに手伝ってもらいましょう。まずは今日、「今日の3つ」を1つ書くところから始めてみてください。
