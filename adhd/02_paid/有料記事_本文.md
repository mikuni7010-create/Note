## 【無料部分】

やらなければいけないことは、ちゃんと分かっている。

分かっているのに手が動かない。スマホで時間を確認するつもりが、気づいたら40分たっている。夕方になって「今日はもう無理だ」と思い、夜になると、何もしなかった1日を思い返して眠れなくなる。翌朝、同じ1日がまた始まる。

これを「やる気がない」「だらしない」で片付けるのは簡単だが、そう言われて直った人を、私はあまり知らない。

### 先延ばしは、怠けとは少し違う

先延ばしの研究では、人が作業を後回しにするのは、その作業が面倒だからというより、作業に向き合うときの不快な気分から逃げたいからだ、と説明されることが多い。不安、退屈、何から始めればいいか分からない混乱。そういう気分を、スマホやほかの用事が一時的に消してくれる。だから手が伸びる。

もうひとつは、時間の感じ方だ。人は、今すぐ手に入る小さな楽しみを、あとで手に入る大きな成果より高く見積もる。締め切りが遠いうちは、作業の重みがほとんど感じられない。それが目の前に迫った瞬間、急に重くなる。前日の夜にだけ集中できるのは、このためだ。

この2つが強く出る人ほど、「やる気が出たらやろう」という方法では動けない。やる気は、作業の前ではなく、作業を始めたあとに遅れてやってくることが多いからだ。

### 必要なのは、始める前の摩擦を減らす仕組み

だから考えるべきなのは、やる気を出す方法ではなく、やる気がない状態でも最初の一歩を踏み出せる仕組みのほうになる。

海外では、こうした困りごとを前提にした「ADHDプランナー」という書き込み式の手帳が、ひとつのジャンルになっている。アメリカの通販サイト「Etsy」で検索すると、印刷用のテンプレートが大量に出てくる。共通しているのは、書くことを増やすのではなく、決めることを減らす作りになっている点だ。

このプランナーは、その考え方を日本の生活に合わせて、A4で印刷できる9ページにまとめたものになる。

入っているのは、頭の中を全部書き出すページ、今日の3つと時間割を書くページ、大きな作業を小さく分けるシート、週の時間割、見積もりと実際の時間を比べるシート、ごほうびを先に決めておくページ、習慣の記録、週のふりかえり。それから、手が止まった作業をChatGPTやClaudeに小さく分けてもらうための指示文を5つ付けた。

### どんな人に合うか

やることが多いと固まってしまう人。時間の見積もりがいつもずれる人。普通の手帳が続かなかった人。診断を受けているかどうかは関係ない。

逆に、紙に書くことそのものが苦痛な人には合わないと思う。それから、これは予定と作業を整理するための道具で、治療の代わりにはならない。困りごとが生活に大きく響いているときは、医療機関や相談窓口に頼ってほしい。

このプランナーで先延ばしがなくなる、とは言わない。変えられるのは、「何から始めるか」を頭の中ではなく紙の上で決められるようになること。そのくらいの小さな変化だ。ただ、その小さな変化があるかないかで、夕方の「今日はもう無理だ」の回数は変わってくる。

プランナーのうち「今日のページ」1枚は、こちらの記事で配布している。合うかどうか、先に試してもらってかまわない。（ここに無料記事へのリンク）

## 【有料部分】

### ダウンロード

（ここにPDF「プランナー本体.pdf」を添付）

A4で印刷して使う。家にプリンターがなければ、コンビニのネットプリントで出せる。何度印刷してもかまわないが、個人で使う範囲にとどめて、ファイルの再配布はしないでほしい。iPadなどでPDFに直接書き込むこともできる。

### 9ページ全部は使わなくていい

最初に言っておくと、9ページを全部使う必要はまったくない。全部を使おうとした時点で、それ自体が「大きすぎる一歩」になる。

最初の1週間は、ブレインダンプ、今日のページ、週のふりかえりの3枚だけでいい。ブレインダンプは気になったときに、今日のページは毎日、ふりかえりは週末に1回。慣れてきたら、困りごとに合わせて1枚ずつ足していく。

取りかかれない作業があるなら、タスク分解シートを足す。予定がいつも押すなら、見積もり練習シート。1週間があっという間に終わるなら、週間タイムブロック。気持ちが動かないなら、ごほうびメニュー。続けたい習慣があるなら、月間トラッカー。

### ブレインダンプ

気になっていることを、大きさも順番も気にせず全部書き出すページ。仕事、家のこと、お金と手続き、人との約束、なんとなく気になること、やりたいこと、の6つの枠に分けてある。

終わっていない用事は、終わっていないというだけで頭の片隅に居座り続ける。心理学では「ツァイガルニク効果」と呼ばれる現象で、未完了のことほど記憶に残りやすい。いくつもの用事が同時に居座ると、それだけで頭が疲れる。紙に書き出すのは、その居座りを外に移すためだ。

書き終えたら、今日やるものに★、誰かに頼めるものに→、やらなくていいものに✕をつける。この中でいちばん効くのは✕だと思う。やらないと決めたものは、頭から降ろしていい。

### 今日のページ

今日の3つを書く。3つ全部終わらなくてもいい。1つ終われば、その日は合格にする。

それぞれに見積もりの時間と、最初の一歩を書く欄がある。最初の一歩は「2分でできること」まで小さくする。「企画書を書く」ではなく「ファイルを開いてタイトルだけ入れる」。小さすぎるくらいでちょうどいい。始めてしまえば、続きは案外動く。

下にある「明日に回すこと」の欄には、今日やらないと決めたことを書く。ここに書いたものは、今日のうちは忘れていい。忘れていいと決めておくと、夜の頭が少し静かになる。

### タスク分解シート

ひとつの一歩は15分以内を目安にする。15分の一歩でも手が止まるなら、まだ大きい。「パソコンを開く」「ファイル名を決める」「1行目だけ書く」。そこまで小さくしていい。

### 見積もり練習シート

作業の前に何分かかりそうかを書き、終わったら実際の時間を書く。右端の欄に「実際÷見積もり」を書いていく。2週間ほど続けて、その平均を出す。

これが自分の倍率になる。たとえば1.8倍だったら、30分と思った作業には55分の枠を取る。最初から倍率をかけた予定を立てると、予定が崩れる回数が目に見えて減る。予定どおりにいかないのは能力のせいではなく、誰にでもある見積もりの癖で、それを数字で知っているかどうかの差だと思う。

### ごほうびメニュー

作業のあとの楽しみを、あらかじめ一覧にしておくページ。海外では「ドーパミンメニュー」と呼ばれている。5分でできるもの、30分くらいのもの、週に1回の特別なもの、の3段に分けて書く。

先に決めておくのは、作業が終わった瞬間に「何をしようか」と考える余地をなくすため。その余地があると、たいていスマホに手が伸びる。SNSや動画の連続再生のように、始めると止まらないものは、ごほうびにするなら時間を区切るか、別のものに置き換えたほうがいい。

### 習慣トラッカーと週のふりかえり

トラッカーは、全部埋めるための表ではなく、できた日を数えるための表。空いた日はそのままでいい。

ふりかえりは、反省会ではなく来週の自分への申し送りとして書く。できたことから書き始める。できなかったことは、責めずに事実だけを書く。

### AIに作業を小さく分けてもらう

手が止まったときは、AIに一歩目を考えてもらうのも手だ。ChatGPT、Claude、Geminiなどに、下の文をそのまま貼る。【　】の中だけ書き換える。名前や住所などの個人情報は入れないこと。

作業を2分の一歩まで分けてもらう

```
私は作業に取りかかるのが苦手です。次の作業を、1つあたり15分以内でできる小さな手順に分けてください。
最初の手順は「2分以内にできること」にしてください。
手順は多くても7つまでにして、それぞれに目安の時間（分）を付けてください。
作業：【例：確定申告の書類をそろえる】
```

書き出したものを仕分けてもらう

```
次は、私が頭の中にあることを全部書き出したリストです。
「今日やる」「今週やる」「誰かに頼める」「やらなくていい」の4つに分けてください。
判断に迷うものは「確認が必要」として、何を確認すればいいかを1行で書いてください。
リスト：【書き出した内容を貼る】
```

見積もりに自分の倍率をかけてもらう

```
私は作業時間を短く見積もりがちで、実際には平均【例：1.8】倍かかります。
次の作業リストについて、私の見積もりに倍率をかけた現実的な時間と、今日の残り【例：4】時間に収まるかどうかを表にしてください。
収まらない場合は、明日に回す候補を提案してください。
作業と見積もり：【例：メール返信 15分、資料修正 30分、買い物 20分】
```

どうしても動けないときの、最初の行動を1つだけ出してもらう

```
次の作業に、どうしても取りかかれません。
責めたり励ましすぎたりせず、今すぐできる最初の行動を1つだけ、具体的に提案してください。
その行動は、立ち上がらなくてもできるものだと助かります。
作業：【例：部屋の片付け】
```

1週間の予定を枠に置いてもらう

```
次の予定と、今週やりたいことをもとに、週間の時間割を作ってください。
条件：1日に1〜2か所は空き時間を残す。1つの作業は90分以内にして、間に休憩を入れる。疲れやすい夕方以降には重い作業を置かない。
決まっている予定：【例：月〜金 9時〜18時 仕事】
今週やりたいこと：【例：役所の手続き、部屋の片付け、友人への返信】
```

AIの答えはたたき台なので、合わなければ遠慮なく直していい。体調や服薬のことは、AIではなく医師に聞いてほしい。

### 書けない日が続いたら

白紙の日があっても、さかのぼって埋めなくていい。戻るときは今日のページ1枚から。2週間空いたら、ブレインダンプからやり直す。

手帳が止まったことに気づいて、もう一度開いた。その時点で、前回よりひとつ先に進んでいる。
