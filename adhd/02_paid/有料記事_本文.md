## 【無料部分】

やらなければいけないことは、ちゃんと分かっている。

分かっているのに、手が動かない。

洗濯物をたたもうと思って、動画をつけながら始める。気づくと動画だけ見ていて、洗濯物は山のまま。メールを書いている途中で別のことを思い出して、それを調べ始める。メールは下書きのまま、3日たつ。

ADHDの傾向がある私の1日は、だいたいこんなふうに崩れていく。

逆に、一度始めたことは止められない。調べものを始めたら、気づくと夜中の3時。睡眠時間を削って、次の日に体調を崩す。それで予定がまた後ろにずれる。

「やる気がない」「だらしない」。

何度も言われたし、自分でもそう思ってきた。でも、そう言われて直ったことは一度もない。

### 先延ばしは、怠けとは少し違う

あとから知ったことだけど、先延ばしの研究では、人が作業を後回しにするのは、作業そのものが面倒だからというより、作業に向き合ったときの嫌な気分から逃げたいからだ、と説明されることが多いらしい。

不安。退屈。何から始めればいいか分からない混乱。

そういう気分を、スマホやほかの用事が一時的に消してくれる。だから手が伸びる。

読んだとき、少し救われた気がした。

### 締め切りは、近づくまで重さがない

もう一つは、時間の感じ方だ。

人は、今すぐ手に入る小さな楽しみを、あとで手に入る大きな成果より高く見積もる。締め切りが遠いうちは、作業の重みがほとんど感じられない。それが目の前に来た瞬間、急に重くなる。

前日の夜にだけ集中できるのは、たぶんこのせいだ。

### やる気は、あとから来る

私みたいなタイプほど、「やる気が出たらやろう」では動けない。

やる気は、始める前ではなく、始めたあとに遅れてやってくることが多いからだ。

【画像：図1_やる気の順番.png】

だから考えたいのは、やる気を出す方法ではない。

やる気がない状態のまま、最初の一歩だけ踏み出せる仕組みのほうだ。

### 海外では、ひとつのジャンルになっている

こうした困りごとを前提にした書き込み式の手帳が、海外では「ADHDプランナー」と呼ばれて定着している。アメリカの通販サイト「Etsy」で検索すると、印刷用のテンプレートが大量に出てくる。

共通しているのは、書くことを増やすのではなく、決めることを減らす作りになっている点だ。

日本語で使えるものが見つからなかったので、その考え方を日本の生活に合わせて、自分用に作った。A4で印刷できる9ページにまとめたのが、このプランナーになる。

【画像：図2_全9ページ.png】

中身はこうなっている。

頭の中を全部書き出すページ。今日の3つと時間割を書くページ。大きな作業を小さく分けるシート。週の時間割。見積もりと実際の時間を比べるシート。ごほうびを先に決めておくページ。習慣の記録。週のふりかえり。

それから、手が止まった作業をChatGPTやClaudeに小さく分けてもらうための指示文を5つ。

### 合う人、合わない人

やることが多いと固まってしまう人。時間の見積もりがいつもずれる人。普通の手帳が続かなかった人。思いついたことに引っぱられて、元の作業に戻れない人。診断を受けているかどうかは関係ない。

紙に書くこと自体が苦痛な人には、たぶん合わない。

### 変わるのは、ほんの少し

このプランナーで先延ばしがなくなる、とは言わない。私も今だに、スマホは5秒で見失う。

変えられるのは、「何から始めるか」を頭の中ではなく、紙の上で決められるようになること。そのくらいの小さな変化だ。

ただ、その小さな変化があるかないかで、夕方の「今日はもう無理だ」の回数は、私の場合ははっきり減った。

「今日のページ」1枚だけは、こちらの記事で配布している。合うかどうか、先に試してもらってかまわない。

（ここに無料記事へのリンク）

同じことで困っている方で、必要だと感じた方は、ぜひ使ってみてください。

## 【有料部分】

### ダウンロード

（ここにPDF「プランナー本体.pdf」を添付）

A4で印刷して使う。プリンターがなければ、コンビニのネットプリントで出せる。

何度印刷してもかまわない。ただし個人で使う範囲にとどめて、ファイルの再配布はしないでほしい。iPadなどで、PDFに直接書き込むこともできる。

### 全部は使わない

最初に言っておくと、9ページ全部を使う必要はまったくない。

全部使おうとした時点で、それ自体が「大きすぎる一歩」になる。私は一度それで失敗した。

最初の1週間は、この3枚だけでいい。

ブレインダンプ（気になったとき）
今日のページ（毎日）
週のふりかえり（週末に1回）

慣れてきたら、困りごとに合わせて1枚ずつ足していく。

取りかかれない作業があるなら、タスク分解シート。予定がいつも押すなら、見積もり練習シート。1週間があっという間に終わるなら、週間タイムブロック。気持ちが動かないなら、ごほうびメニュー。

### ブレインダンプ

気になっていることを、大きさも順番も気にせず、全部書き出すページ。

私は、気になることがあると、それが済むまで他のことに手がつかない。終わっていない用事は、終わっていないというだけで頭の片隅に居座る。心理学では「ツァイガルニク効果」と呼ばれていて、未完了のことほど記憶に残りやすいそうだ。

書き出すのは、その居座りを紙に移すためだ。

作業中に何か思いついたときも、ここに書く。書いたら、元の作業に戻る。思いつきを「捨てる」のではなく「預ける」感覚だ。預けてあると分かっていれば、今すぐ追いかけなくていい。

書き終えたら印をつける。今日やるものに★。誰かに頼めるものに→。やらなくていいものに✕。

いちばん効くのは、✕だと思う。

### 今日のページ

【画像：図4_今日のページ.png】

今日の3つを書く。

3つ全部終わらなくていい。1つ終われば、その日は合格にする。

それぞれに、見積もりの時間と最初の一歩を書く。最初の一歩は「2分でできること」まで小さくする。

「企画書を書く」ではなく、「ファイルを開いてタイトルだけ入れる」。

小さすぎるくらいで、ちょうどいい。始めてしまえば、続きは案外動く。

下の「明日に回すこと」には、今日やらないと決めたことを書く。

これは、後回しにしたものを忘れてしまう自分のために作った欄だ。支払いの用紙を「あとで」と置いて、期限が過ぎてから引き出しの奥で見つけたことがある。書いてあれば、明日の自分が拾える。書いたものは、今日のうちは忘れていい。

### タスク分解シート

一つの一歩は15分以内が目安。

それでも手が止まるなら、まだ大きい。「パソコンを開く」「ファイル名を決める」「1行目だけ書く」。そこまで刻んでいい。

### 見積もり練習シート

作業の前に、何分かかりそうかを書く。終わったら、実際の時間を書く。右端に「実際÷見積もり」を書いていく。

2週間ほど続けて、その平均を出す。

これが自分の倍率になる。

【画像：図3_見積もりの倍率.png】

たとえば1.8倍なら、30分と思った作業には55分の枠を取る。最初から倍率をかけておくと、予定が崩れる回数ははっきり減る。

予定どおりにいかないのは、能力のせいではない。誰にでもある見積もりの癖で、それを数字で知っているかどうかの違いだ。

### ごほうびメニュー

作業のあとの楽しみを、先に一覧にしておくページ。海外では「ドーパミンメニュー」と呼ばれている。

5分でできるもの。30分くらいのもの。週に1回の特別なもの。3段に分けて書いておく。

先に決めておくのは、作業が終わった瞬間に「何しようか」と考える隙をなくすためだ。その隙があると、たいていスマホに手が伸びる。

気をつけたいのは、始めると止まらないものだ。

私にとっては、調べものや動画がそうだった。ちょっとだけのつもりが夜中まで続いて、睡眠も体調も削る。こういうものをごほうびにするなら、先にタイマーをかけるか、終わりのはっきりしたもの（1曲、1杯のお茶）に置き換えたほうがいい。

### 習慣トラッカーと、週のふりかえり

トラッカーは、全部埋めるための表ではない。できた日を数えるための表だ。空いた日は、空いたままでいい。

ふりかえりは反省会ではなく、来週の自分への申し送り。できたことから書く。できなかったことは、責めずに事実だけ。

### AIに、一歩目を考えてもらう

手が止まったときは、AIに一歩目を出してもらうのも手だ。

ChatGPT、Claude、Geminiなどに下の文をそのまま貼って、【　】の中だけ書き換える。名前や住所などの個人情報は入れないこと。

作業を2分の一歩まで分けてもらう

```
私は作業に取りかかるのが苦手です。次の作業を、1つあたり15分以内でできる小さな手順に分けてください。
最初の手順は「2分以内にできること」にしてください。
手順は多くても7つまでにして、それぞれに目安の時間（分）を付けてください。
作業：【例：確定申告の書類をそろえる】
```

書き出したものを仕分けてもらう

```
次は、私が頭の中にあることを全部書き出したリストです。
「今日やる」「今週やる」「誰かに頼める」「やらなくていい」の4つに分けてください。
判断に迷うものは「確認が必要」として、何を確認すればいいかを1行で書いてください。
リスト：【書き出した内容を貼る】
```

見積もりに自分の倍率をかけてもらう

```
私は作業時間を短く見積もりがちで、実際には平均【例：1.8】倍かかります。
次の作業リストについて、私の見積もりに倍率をかけた現実的な時間と、今日の残り【例：4】時間に収まるかどうかを表にしてください。
収まらない場合は、明日に回す候補を提案してください。
作業と見積もり：【例：メール返信 15分、資料修正 30分、買い物 20分】
```

どうしても動けないとき、最初の行動を1つだけ出してもらう

```
次の作業に、どうしても取りかかれません。
責めたり励ましすぎたりせず、今すぐできる最初の行動を1つだけ、具体的に提案してください。
その行動は、立ち上がらなくてもできるものだと助かります。
作業：【例：部屋の片付け】
```

1週間の予定を枠に置いてもらう

```
次の予定と、今週やりたいことをもとに、週間の時間割を作ってください。
条件：1日に1〜2か所は空き時間を残す。1つの作業は90分以内にして、間に休憩を入れる。疲れやすい夕方以降には重い作業を置かない。
決まっている予定：【例：月〜金 9時〜18時 仕事】
今週やりたいこと：【例：役所の手続き、部屋の片付け、友人への返信】
```

AIの答えは、たたき台だ。合わなければ遠慮なく直していい。

### 書けない日が続いたら

白紙の日があっても、さかのぼって埋めなくていい。

戻るときは、今日のページ1枚から。2週間空いたら、ブレインダンプからやり直す。

私も、何度も止まっている。そのたびに、今日のページ1枚から戻ってきた。

手帳が止まっていたことに気づいて、もう一度開いた。

その時点で、前回より一つ先に進んでいる。
