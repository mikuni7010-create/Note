# SNS運用計画（X・TikTok）

## 全体の流れ
TikTok（新しい人に見つけてもらう）→ X（関係を深める・日々の接点）→ note無料記事（信頼）→ note有料記事（購入）

- TikTokは、フォロワーが少なくても「おすすめ」に載れば初対面の人に届く。拡散の入口として使う。
- Xは、返信や会話で関係を作る場所。noteへの導線はプロフィールと固定ポストに置く。
- どちらも名前・アイコン・自己紹介をnoteとそろえる（「今日の3つ」）。

## 共通の立ち位置
- 「ADHDの傾向がある本人が、自分の困りごとのために道具を作っている」。
- 発信の軸は3つ。
  1. あるある（共感）：スマホ5秒で見失う、忘れ物で戻る、過集中で夜中の3時、など
  2. 仕組み（納得）：なぜそうなるのかを、やさしい言葉で（計画錯誤、ツァイガルニク効果など）
  3. 小さな工夫（行動）：今日からできる一手と、プランナーのページの使い方
- 割合の目安：あるある4、仕組み3、工夫3。
- 「物忘れ＝ADHD」のように、誰にでもある特徴をADHDだと断定しない。海外の調査では、ADHD関連の人気動画の多くが誤解を招く内容と評価されており、ここを丁寧にすることが差別化になる。

## 海外で反応が良かった切り口（日本向けに使う）
- 「日付入りの手帳は、1週間空くと白紙の山になって自己嫌悪になる」→ このプランナーは日付なし。空白を気にせず再開できる点を推す。
- 「何冊も挫折した人が、ようやく使えた手帳」という告白型の書き出し。
- 「コメントで○○と書いてくれたら送ります」型の誘導（TikTokで多い）。→ 日本では「プロフィールのリンクから無料の1枚を配布中」に置き換える。

## X（旧Twitter）

### プロフィール
- 名前：今日の3つ｜ADHD傾向の手帳づくり
- 自己紹介：noteと同じ文章を140字以内に調整して使う
- 固定ポスト：無料の「今日のページ」配布ポスト（noteの無料記事へのリンク付き）

### 投稿の型
| 型 | 例 | 頻度 |
|---|---|---|
| あるある1行 | 「スマホを机に置く。5秒後、スマホを探している。」 | 週3 |
| 仕組みの解説（3〜5行） | 「30分のつもりが2時間になるのは、計画錯誤という誰にでもある見積もりの癖。私は自分の倍率を測ってから予定が崩れにくくなった」 | 週2 |
| 小さな工夫 | 「思いつきは追いかけずに、紙に"預ける"。書いたら元の作業に戻る」 | 週2 |
| 問いかけ | 「忘れ物で家に戻った最高回数、何回ですか。私は3回」 | 週1 |
| note告知 | 新しい記事が出た日のみ。本文で価値を書き、リンクは最後に1回 | 記事公開日 |

### 1日の動き（10〜15分）
1. 朝：予約しておいた投稿が出る（Xの予約投稿機能を使い、週1回まとめて予約）
2. 昼か夜：自分の投稿への返信に、すべて一言返す（返信の往復が最も評価されやすい）
3. 同じ悩みを書いている人の投稿に、共感や小さな工夫を一言返信する（5件程度）

### やらないこと
- 自動でフォロー・いいね・返信するツールの使用（凍結の原因になる）
- 同じ文章の連投、ハッシュタグの付けすぎ（1〜2個まで）
- 他の人の投稿への宣伝目的の返信

## TikTok

### 顔出しなしでできる形式
| 形式 | 内容 | 作業 |
|---|---|---|
| 写真スライド（フォトモード） | 白地に黒文字のスライド6〜8枚。あるある→仕組み→工夫の順 | Claudeが画像を作成。投稿するだけ |
| 手元の動画 | プランナーに書き込む手元だけを撮影し、文字を重ねる | 手元を15〜30秒撮る |
| 画面の文字だけの動画 | スライドを動画にして、BGMを付ける | アプリで画像を並べる |

最初の2週間は「写真スライド」だけでよい。

### 伸びやすい作り方
- 1枚目で自分ごとにさせる：「スマホを5秒で見失う人へ」「手帳が3日で止まる人だけ見て」
- 最後まで見たくなる順番：1枚目に問い、最後の1枚に答えと工夫を置く
- 保存したくなる中身：最後の1〜2枚に、すぐ使える工夫やチェックリストを置く（保存は評価されやすい）
- 説明文の最後に「プロフィールのリンクから、今日のページ1枚を配布しています」

### 頻度と作業時間
- 週3本（火・木・土）。1本あたり投稿作業5分
- コメントには一言返す（1日5分）
